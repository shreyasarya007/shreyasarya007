# Shreyas Arya Jaiswal

**Electronics and Communication Engineering undergraduate | Manipal Institute of Technology, India**

I work on projects across antenna design, digital IC design, and PCB development. I am building my experience in analog and RF integrated circuits, with a current focus on asynchronous ADC design in Cadence Virtuoso.

## Selected projects

| Project | Focus | Tools |
| --- | --- | --- |
| [Asynchronous ADC Design](https://github.com/shreyasarya007/asynchronous-adc-design) | Ongoing schematic-level ADC building blocks, logic cells, and comparator design | Cadence Virtuoso, GPDK180 |
| [8-bit Counter RTL Synthesis](https://github.com/shreyasarya007/rtl-counter-synthesis) | Verilog RTL, a self-checking testbench, timing constraints, and a Genus synthesis flow | Verilog, Cadence Genus |
| [Micromouse PCB Design](https://github.com/shreyasarya007/micromouse-pcb-design) | Two hardware design iterations with schematics and PCB layouts | KiCad |
| [Sub-6 GHz UWB MIMO Antenna](https://github.com/shreyasarya007/sub-6ghz-uwb-mimo-antenna) | Single-element and MIMO antenna design project | Ansys HFSS |
| [Ku-Band MIMO Microstrip Antenna](https://github.com/shreyasarya007/ku-band-mimo-microstrip-antenna) | Ku-band MIMO and single-element microstrip antenna design | Ansys HFSS |

Each repository documents the available design files, setup requirements, and current limitations. The ADC project is in progress; the repositories do not imply that every design has been fabricated or independently validated.
